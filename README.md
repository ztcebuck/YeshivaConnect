# YeshivaConnect (ישיבה קונקט) ⚡

תוכנה לשיתוף קבצים, תיקיות וצ'אט מהיר ברשת מקומית (LAN / Wi-Fi Hotspot) — **ללא צורך בחיבור לאינטרנט**.
מותאמת במיוחד לסביבות סגורות, ישיבות, מוסדות לימוד ורשתות מקומיות.

---

## ✨ תכונות עיקריות

- 🚀 **העברת קבצים ותיקיות במהירות מקסימלית:** העברה ישירה מבוססת פרוטוקול TCP בין מחשבים באותה הרשת ללא הגבלת גודל מעשית.
- 📡 **יצירת נקודה חמה (Hotspot) וחיבור מהיר:** יצירת רשת אלחוטית מקומית ישירות מהתוכנה וחיבור מהיר באמצעות סריקת קוד QR.
- 🌐 **שרת שיתוף דפדפן (Web Share):** שיתוף והורדת קבצים גם למכשירים שאין עליהם את התוכנה מותקנת (דרך דפדפן האינטרנט).
- 💬 **צ'אט מקומי והיסטוריה:** שליחת הודעות טקסט וקישורים עם שמירה מקומית במסד נתונים SQLite.
- 🔍 **גילוי אוטומטי של מחשבים ברשת:** שימוש ב-UDP Broadcast לאיתור עמיתים מחוברים באופן אוטומטי.
- 🔒 **עבודה אופליין מלאה:** כל הפונטים, הספריות והאייקונים ארוזים מקומית ללא תלות בשרתים חיצוניים.

---

## 🛠️ דרישות מערכת והתקנה

### דרישות:
* **מערכת הפעלה:** Windows 10 / 11
* **Python:** 3.10 ומעלה

### התקנה:
1. שכפל את המאגר:
   ```bash
   git clone https://github.com/ztcebuck/YeshivaConnect.git
   cd YeshivaConnect
   ```

2. התקן את התלויות:
   ```bash
   pip install -r requirements.txt
   ```

3. הרצת התוכנה:
   ```bash
   python main.py
   ```

---

## 📦 בניית קובץ הרצה עצמאי (EXE)

לבניית קובץ `YeshivaConnect.exe` יחיד שאינו דורש התקנת פייתון:

```bash
pyinstaller YeshivaConnect.spec
```
הקובץ המוכן ייווצר בתוך תיקיית `dist/`.

---

## 📂 מבנה הפרויקט

```text
├── main.py                 # קובץ הכניסה הראשי, ניהול הממשק (Eel) ואירועים
├── socket_manager.py       # שרת/לקוח TCP להעברות ו-UDP Discovery
├── web_share.py            # שרת HTTP לשיתוף דרך דפדפן
├── network_manager.py      # ניהול נקודה חמה ורשתות Wi-Fi
├── database_manager.py     # מסד נתונים מקומי (SQLite)
├── web/                    # קבצי הממשק הגרפי (HTML, CSS, JS, Fonts)
├── icon.ico                # אייקון התוכנה
├── YeshivaConnect.spec     # הגדרות בנייה ל-PyInstaller
├── requirements.txt        # תלויות פייתון
└── README.md               # תיעוד הפרויקט
```
